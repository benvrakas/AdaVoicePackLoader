# Ada Voice Pack Loader: architecture

A client-side mod (`RequiredOnRemote: false`, Windows target only) that plays ADA voice lines from separate content-pack
mods. Reuses BoomBoxPlus's ADA technique (its `Docs/EasterEggs.md` and `D:\SFMod\Tools\ADA\README.md` have the history).

## Packs

A pack is a content-only mod, depending on this one, with `Resources/AdaPack/pack.json` and `pack.bnk`. The loader finds
packs by scanning every enabled plugin's `Resources/AdaPack/pack.json` (`FAdaPackRegistry::Discover`). pack.json:

| Field | Meaning |
|---|---|
| `format` | 1 |
| `id`, `name` | pack id (unique across installed packs) and display name |
| `bank`, `bankName` | bank file next to pack.json, and the prefix of its Wwise event names |
| `minGapSeconds` | shortest time between two lines of this pack (default 60) |
| `lines[]` | `id`, `subtitle`, `seconds` (clip length), `trigger`, `chance`, `cooldown`, `once` |

Each line's event is `<bankName>_<id>`; Wwise's id is the FNV-1 hash of the lowercase name.

The pack mods are generated by `D:\SFMod\Tools\AdaPacks\adapack.py` from a `lines.csv`. The CSV is only the tool's
input: players never get it. The tool makes the speech with Google TTS, applies BoomBoxPlus's ADA tone/doubling
(`D:\SFMod\Tools\ADA\make_bank.py`, `tone_and_level` and `assemble_bank`), and writes the finished mod folder.

## Playback

`UAdaVoicePlayer` (ticked from a core ticker once any pack is installed) is `AddToRoot`ed. A line is queued in the game's
message box as a runtime `UFGMessage` from ADA's sender, so her box and jingle show; a hook on
`UFGAudioMessage::StartPlayback` starts the voice by posting the line's Wwise event on the box's own emitter (ADA's voice
bus mixes it like her own lines). Without a box the event plays on the mod's own game object, with no subtitle. If the
player closes the box early the voice stops. The messages are removed from the game's saved "played messages" lists
every 5 s, or saves would warn about unknown objects.

The Wwise functions (`LoadBankMemoryCopy`, `PostEvent`, `RegisterGameObj`, `StopPlayingID`) are found by exported name in
the game's Wwise DLL at runtime, as BoomBoxPlus does, since the kit's Wwise version differs from the game's. Banks load
once per session, when the first world is up (`FAdaPackRegistry::LoadBanks`).

## /adapack on a client

SML sends every chat line starting with `/` to the server, and a dedicated server doesn't have this mod (it is
client-only), so it answers "Unknown command". A hook on `AFGPlayerController::EnterChatMessage` catches `/adapack` on a
client (`NM_Client`) before the game or SML see it, cancels the call so nothing reaches the server, and runs the command
itself (`AAdaChatCommand::Execute`) with `UAdaLocalCommandSender`, whose replies go straight into the local chat box.
SML's `AChatCommandSubsystem` can't be used there: it spawns only on the server (1.1.3 tried it and answered "isn't ready
yet" on every client). Single-player and the host still go through SML as before.
